# Odoo National Hackathon 2026 — Event Brief

## 1. Overview
The Odoo National Level Hackathon 2026 brings together top engineering teams across the country to design, build, and present robust, innovative software solutions within a fast-paced competitive setting.

## 2. Competition Structure
- **Round 1: Virtual Round**
  - Problem statement release and requirements analysis.
  - Core architecture design and module scoping.
  - Rapid prototyping, API integration, and MVP development.
  - Virtual code review and evaluation.
- **Round 2: National Finale**
  - Advanced feature development, end-to-end integration, performance optimization, and live jury demonstration.
