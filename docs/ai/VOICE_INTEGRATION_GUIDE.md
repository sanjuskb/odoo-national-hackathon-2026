## 1. Overview & Architecture

The Brightloop Voice Assistance system automatically triggers a proactive customer welcome and onboarding call upon confirmed subscription activation. The architecture decouples speech synthesis (Murf TTS) from telephony carrier delivery (Twilio / Mock), guaranteeing safety, privacy, consent compliance, and resilience.

```
Subscription Activation Event (UUID)
         │
         ▼
[ Idempotency Deduplication Gate ]
         │ (Pass if not previously processed)
         ▼
[ Customer Consent Verification ] ──────► (Consent = False) ──► Mark Status: CANCELLED (No Dispatch)
         │ (Consent = True)
         ▼
[ Fetch Authorized Customer Data ] (Plan name, renewal date, features)
         │
         ▼
[ Grounded Dialogue Script Generation ]
         │
         ▼
[ Speech Synthesis ] ──► Murf Studio API (or MockMurfTTSProvider fallback)
         │               └─► Generates raw audio stream (MP3)
         ▼
[ Telephony Carrier Dispatch ] ──► Twilio Voice REST API (or MockTelephonyProvider)
         │                         └─► E.164 Number Validation & TwiML Delivery
         ▼
[ Webhook Status Callback ] ──► POST /voice/twilio/callback (queued -> in-progress -> completed)
```

## 2. Configuration Variables

Set these in your local, git-ignored `.env` file (never commit live credentials):

```ini
# Murf Text-to-Speech Provider
MURF_API_KEY=your_murf_api_key_here
MURF_VOICE_ID=en-US-marcus
MURF_TIMEOUT_SECONDS=15.0

# Telephony Configuration
TELEPHONY_PROVIDER=twilio          # 'mock' or 'twilio'
USE_MOCK_PROVIDERS=false           # false enables live providers when keys are set
CALL_ASSISTANCE_WINDOW_SECONDS=60
CALL_MAX_RETRIES=3

# Twilio Telephony Credentials
TWILIO_ACCOUNT_SID=ACXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX
TWILIO_AUTH_TOKEN=your_twilio_auth_token_here
TWILIO_PHONE_NUMBER=+15551234567
TWILIO_STATUS_CALLBACK_URL=https://your-public-domain.com/voice/twilio/callback
TWILIO_TIMEOUT_SECONDS=10.0
```

## 3. Murf Text-to-Speech Setup

1. **API Endpoint:** `https://api.murf.ai/v1/speech/generate`
2. **Authentication:** Sent via `api-key` header.
3. **Payload Structure:**
   - `voiceId`: Murf voice ID (e.g., `en-US-marcus` or `en-US-natalie`).
   - `text`: Grounded dialogue generated by `AIAssistanceCallService`.
   - `rate`: Rate modifier percentage (-50 to +50, where 0 is standard speed).
   - `format`: `MP3`.
4. **Audio Retrieval:**
   - The adapter automatically handles both `encodedAudio` (base64) and `audioFile` (CDN URL download).
   - Audio bytes are cached in-memory and streamed to the evaluator via `GET /voice/assistance-call/audio/{call_id}`.
5. **Fallback Safety:** If Murf API returns 401, 429, or times out, the system falls back to text-based dialogue without blocking customer activation.

---

## 4. Twilio Telephony Setup

1. **REST API Endpoint:** `https://api.twilio.com/2010-04-01/Accounts/{AccountSid}/Calls.json`
2. **Authentication:** HTTP Basic Auth with `(AccountSid, AuthToken)`.
3. **Safety Dry-Run Gate:**
   - In `TwilioTelephonyProvider`, `dry_run: bool = True` is enforced by default.
   - During development and local testing, requests are fully validated, TwiML is generated, and a realistic Twilio SID (`CA...`) is returned with `is_simulated = true`.
   - Outbound carrier calls require explicit authorization (`allow_live_dispatch=True`).
4. **E.164 Telephone Formatting:**
   - Destination numbers must match international E.164 format: `+` followed by country code and digits (e.g. `+15550199` or `+919876543210`).
   - Invalid numbers fail closed with a `ValidationError`.
5. **TwiML Generation:**
   - If audio is hosted, plays the audio stream: `<Play>{audio_url}</Play>`.
   - Otherwise speaks the script using Polly: `<Say voice="Polly.Matthew">{script}</Say>`.

## 5. Webhook Requirements (Public HTTPS)

When running live carrier calls, Twilio requires a public HTTPS URL to deliver status callbacks:
1. Endpoint: `POST /voice/twilio/callback`.
2. Twilio sends `application/x-www-form-urlencoded` data:
   - `CallSid`: Twilio call SID.
   - `CallStatus`: `initiated`, `ringing`, `in-progress`, `completed`, `busy`, `no-answer`, or `failed`.
   - `CallDuration`: Integer duration in seconds.
3. For local development, use an HTTPS tunnel (e.g., Cloudflare Tunnel, ngrok) pointing to `localhost:8000`, and set `TWILIO_STATUS_CALLBACK_URL=https://your-tunnel.ngrok-free.app/voice/twilio/callback`.

## 6. Security, Privacy & Consent Invariants

1. **Explicit Customer Consent:**
   - Customer profile field `call_consent: bool` is checked before any dispatch.
   - If `call_consent == False`, call is recorded as `status: cancelled` with reason `"Customer opted out of phone assistance (consent=False)"`. No call is placed.
2. **PII Masking:**
   - Telephone numbers are masked in all logs and API responses: `+1-****0199`.
3. **Idempotency Deduplication:**
   - Deduplication key: `{subscription_id}:{plan_id}`.
   - Repeated events for the same subscription return the existing call record without placing redundant carrier calls.
