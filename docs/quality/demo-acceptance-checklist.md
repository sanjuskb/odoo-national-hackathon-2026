# Evaluator demo acceptance checklist

- [ ] Explain official problem and Brightloop workflow accurately.
- [ ] Admin, staff and customer role separation proven.
- [ ] Admin creates product/variant with +560 and recurring plan.
- [ ] Quotation template produces a subscription with valid lifecycle.
- [ ] Due invoice contains customer, lines, taxes and discounts.
- [ ] Running billing twice for same period creates only one invoice.
- [ ] Payment updates balances/status, finance dashboard reflects it.
- [ ] Customer portal cannot access another customer's data.
- [ ] Thousands-of-subscriptions performance measured, under two-second pages confirmed.
- [ ] Architecture diagram matches running modules.
- [ ] All claimed sends, printing, automation, password reset actually work—or limitations clearly disclosed.
- [ ] Video stays within five minutes and submitted link accessibility checked.

Only check an item after a verified demonstration or executed test. Do not claim unfinished features.
