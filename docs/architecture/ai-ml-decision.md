# AI/ML decision — no mandatory AI

The four-page official PS does not mention AI/ML as an objective. Registration, authorization, billing schedules, taxes, discounts, ledger payments and reporting are deterministic, auditable workflows. Do not let an LLM set invoice totals, paid status, admin rights or subscription billing periods.

Sanju's critical priorities are integration, test evidence and clear evaluator narrative. Explore optional non-authoritative summary or anomaly hint only if actual user need, data and time permit *after* working P0 flows; distinguish proposal from implementation and verify privacy/fallback. No invented model accuracy.
