## 1. Overview

This directory holds the consolidated canonical schema definitions representing the target state of the Supabase PostgreSQL database. While individual changes are tracked chronologically in `database/migrations/`, this directory provides a reference representation of:

1. Core application tables and column definitions.
2. Primary, foreign, and unique key constraints.
3. Domain `CHECK` constraints and enum types.
4. Custom PostgreSQL stored functions, procedures, and triggers.
