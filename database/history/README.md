## 2. Records Maintained

1. **`CHANGELOG.md`:** Comprehensive, reverse-chronological record of all schema additions, migrations, index updates, and RLS policy changes.
2. **Architecture Decision Records (ADRs):** Explicit rationales for key decisions (e.g. data modeling trade-offs, indexing strategies, authentication mapping).
